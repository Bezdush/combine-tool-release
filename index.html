What it does

  • Source GraphResolve objects, collections, instances and target dependencies.
  • Controlled outputChoose UV and material policies for the combined target.
  • Clear diagnosticsInspect issues and export HTML reports before updating.

Install or update

  1. Save your Blender project and download the ZIP from the Stable or Beta card.
  2. In Blender, open Edit → Preferences → Add-ons → Install from Disk.
  3. Select the ZIP and enable Combine Tool. Keep the ZIP intact; Blender installs it directly.

For an existing installation, use the add-on's update option or install the newer ZIP through Blender. The updater verifies the signed channel manifest and archive checksum before installation.

Documentation

In Blender, mark a target object, select its sources and policies, then review diagnostics before running Update. Combine Tool preserves the source objects while refreshing the target mesh.

For a problem report, include the Combine Tool and Blender versions and steps to reproduce. Browse reports or open an issue.
